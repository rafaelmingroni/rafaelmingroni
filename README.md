## 🚀 Featured project

### [Mingrx](https://github.com/rafaelmingroni/mingrx-app)

**Voice, chat and screen sharing — built to stay light while you play.**

A desktop communication platform for Windows built around communities, text and voice channels, private messages, webcam and screen sharing.

`Electron` · `JavaScript` · `Firebase` · `WebRTC` · `GitHub Actions`

- real-time voice, webcam and screen sharing with WebRTC
- persistent accounts, communities, channels and messages
- Firebase Authentication, Firestore and Realtime Database
- automatic Windows updates through GitHub Releases
- CI and regression validation before releases
- designed around a lightweight, clean desktop experience
