My background combines **software development, data analysis, automation and business operations**. ## 🚀 Featured project — Mingrx

<div align="center">

### Voice, chat and screen sharing — built to stay light while you play.

[![Mingrx Repo](https://github-readme-stats.vercel.app/api/pin/?username=rafaelmingroni&repo=mingrx-app&theme=tokyonight&hide_border=true)](https://github.com/rafaelmingroni/mingrx-app)

</div>

**Mingrx** is a Windows desktop communication platform built around communities, text and voice channels, private messages, webcam and screen sharing.

- 🎙️ real-time voice communication with WebRTC
- 🖥️ webcam and screen sharing
- 💬 persistent communities, channels, DMs and messages
- 🔐 Firebase Authentication and cloud persistence
- ⚡ automatic Windows updates through GitHub Releases
- ✅ CI and regression validation before releases
- 🎮 designed to remain lightweight while gaming

**Core stack:** `Electron` · `JavaScript` · `Firebase` · `WebRTC` · `GitHub Actions`
